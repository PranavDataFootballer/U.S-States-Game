# U.S-States-Game

Overview

The U.S. States Game is an interactive geography quiz built with Python. Players are challenged to name all 50 U.S. states while viewing a blank map of the United States. Each correct answer is displayed on the map in its correct location, making learning both engaging and visual.

The project is an excellent way to practice Python fundamentals, including loops, conditionals, file handling, data processing with Pandas, and graphical programming with the Turtle module.

Features :- 
- Interactive U.S. map
- Validates state names entered by the player
- Displays correctly guessed states on the map
- Tracks progress throughout the game
- Generates a list of states not guessed for future study

Technologies Used :-
- Python 3
- Turtle Graphics
- Pandas
- CSV data handling

Future Improvements :-
- Add difficulty levels
- Include state capitals
- Add a timer or countdown mode
- Display score history
- Add hints for incorrect guesses
- Improve the user interface
